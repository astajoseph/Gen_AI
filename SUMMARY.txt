   • Reduce max_length or batch size

ISSUE #3: Plots Appear Blank
   Symptom: Matplotlib plots don't show
   Root Cause: Missing plt.show() or tight_layout
   Fix: See COLAB_FIXES.md - Fix #3

   • Add plt.show() explicitly

ISSUE #4: Gradio Interface Won't Load
   Symptom: Interface loads but buttons don't work
   Root Cause: Device mismatch or memory

   • Ensure models on correct device
   • Use model.eval() mode

ISSUE #5: Out of Memory Errors
   Symptom: CUDA out of memory
   Root Cause: Large batch size or model
   Fix: See COLAB_FIXES.md - Fix #5

   • Clear cache: torch.cuda.empty_cache()
   • Use CPU for smaller runs
